MarketingBrain Shorts Uploader — 개인정보처리방침 (Privacy Policy)

시행일: 2026-10-07 · 운영: 마케팅브레인 (연락처: brainmarketing@naver.com)

1. 서비스 개요

MarketingBrain Shorts Uploader(이하 "서비스")는 마케팅브레인이 관리를 위임받은 거래처 유튜브 채널에, 마케팅브레인이 제작한 쇼츠 영상을 업로드·예약 공개하기 위한 내부 업무용 도구입니다. 일반 이용자를 대상으로 하지 않으며, 채널 소유자가 직접 권한을 허용한 채널에만 동작합니다.

2. YouTube API 서비스 사용

본 서비스는 YouTube API 서비스(YouTube API Services)를 사용합니다. 서비스를 이용하면 YouTube 서비스 약관(https://www.youtube.com/t/terms)에 동의하는 것으로 간주되며, Google 개인정보처리방침(https://policies.google.com/privacy)이 함께 적용됩니다.

3. 요청하는 권한(OAuth 범위)과 사용 목적

권한목적
https://www.googleapis.com/auth/youtube.upload허용된 채널에 영상 업로드, 제목·설명·태그·공개 예약 설정
https://www.googleapis.com/auth/youtube.readonly권한을 허용한 채널의 이름·ID 확인(올바른 채널에 올리는지 확인용)

이 외의 정보(구독자 정보, 시청 기록, 댓글, 결제 정보 등)는 요청하거나 수집하지 않습니다.

4. 수집·저장하는 정보

  • OAuth 인증 토큰: 채널별 업로드 권한을 유지하기 위해 마케팅브레인 업무용 컴퓨터에만 저장합니다. 외부 서버로 전송하거나 제3자와 공유하지 않습니다.
  • 업로드 기록: 업로드한 파일명, 영상 ID, 예약 시각(중복 업로드 방지용). 마케팅브레인 업무용 컴퓨터에만 저장합니다.
  • 개인 이용자의 개인정보는 수집하지 않습니다.

5. 정보의 제3자 제공·판매

수집한 정보는 판매하거나 광고 목적으로 사용하지 않으며, 법령에 따른 경우를 제외하고 제3자에게 제공하지 않습니다.

6. 권한 철회 방법

채널 소유자는 언제든지 Google 계정 보안 설정의 "서드 파티 연결" 페이지(https://myaccount.google.com/connections)에서 MarketingBrain Shorts Uploader의 액세스를 삭제하여 권한을 철회할 수 있습니다. 철회 즉시 서비스는 해당 채널에 접근할 수 없습니다.

7. 데이터 삭제

권한 철회 또는 위임 관계 종료 시, 또는 brainmarketing@naver.com으로 삭제를 요청하면 해당 채널의 인증 토큰과 업로드 기록을 7일 이내에 삭제합니다. 인증 토큰은 Google 정책에 따라 장기간 사용되지 않으면 자동으로 만료됩니다.

8. 문의

개인정보 관련 문의: brainmarketing@naver.com

(English) Privacy Policy — MarketingBrain Shorts Uploader

Effective 2026-10-07. Operated by MarketingBrain (brainmarketing@naver.com).

  • What it is: an internal tool used by MarketingBrain to upload and schedule Shorts that MarketingBrain produces to YouTube channels of clients who have delegated channel operations to us. It is not offered to the general public.
  • YouTube API Services: This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms). Google Privacy Policy: https://policies.google.com/privacy.
  • Scopes: youtube.upload (upload videos and set title/description/tags/scheduled publish time) and youtube.readonly (read the authorized channel's name/ID to confirm the target channel). No other data is requested.
  • Data stored: OAuth tokens and an upload log (file name, video ID, scheduled time), stored only on MarketingBrain's work computer. Not shared, sold, or used for advertising.
  • Revoking access: Channel owners can revoke access at any time at https://myaccount.google.com/connections.
  • Deletion: Tokens and logs for a channel are deleted within 7 days after access is revoked, the engagement ends, or upon request to brainmarketing@naver.com.
  • Contact: brainmarketing@naver.com
